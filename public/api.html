Quote

GET/api/quote

Returns one anime quote. Add a query parameter to filter the result or use an index for an exact record.

Query Parameters

indexnumber

Return the quote at an exact index.

animestring

Match an anime title exactly.

searchstring

Search the quote, character, or anime title.

const result = await fetch(
  "/api/quote?anime=Naruto&seed=0"
);

console.log(await result.json());
{
  "index": 42,
  "anime": "Naruto",
  "character": "Pain"
}

Quote list

GET/api/quotes

Returns a filtered, paginated list of quote records from the local index.

Query Parameters

searchstring

Search across quote, character, and anime.

limitnumber

Number of records to return, up to 100.

offsetnumber

Number of matching records to skip.

const result = await fetch(
  "/api/quotes?search=power&limit=10"
);

console.log(await result.json());
{
  "total": 184,
  "limit": 10,
  "data": [...]
}

Quote card

GET/api/card

Returns a ready-to-embed SVG or PNG quote card in one of five visual styles.

Query Parameters

stylestring

editorial, cinema, polaroid, terminal, or gallery.

formatstring

Use png for a PNG image or json to include SVG markup in JSON.

const card = "/api/card?index=42&style=gallery";

document.querySelector("img").src = card;

// Returns: image/svg+xml
// Add &format=png for image/png

Anime index

GET/api/animes

Returns every searchable anime title and the total number of titles in the index.

const result = await fetch(
  "/api/animes"
);

console.log(await result.json());
{
  "count": 1260,
  "data": ["Naruto", "Bleach", ...]
}
